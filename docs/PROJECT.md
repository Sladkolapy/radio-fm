# О проекте

**my_music_player** — веб-приложение для прослушивания и управления собственной библиотекой музыки. Аудио и обложки хранятся **локально на сервере** (файловая система + SQLite), а не во внешних облачных стриминг-сервисах.

## Назначение

Проект рассчитан на **личное или небольшое развёртывание**: вы поднимаете бэкенд и фронтенд у себя, регистрируете пользователей, загружаете треки и слушаете их через браузер. Поддерживается разделение **публичных** и **приватных** треков, **фильтрация по настроению (mood)** и **теги** для каталогизации.

## Архитектура

| Слой        | Технологии |
|------------|------------|
| **Backend**  | Node.js, Express, SQLite, JWT, Multer (загрузка файлов) |
| **Frontend** | React 18, TypeScript, Vite, Redux Toolkit, Tailwind CSS, React Router, Axios |

Бэкенд отдаёт REST API и раздаёт/отдаёт метаданные треков; фронтенд — SPA с плеером, формами создания/редактирования треков и админ-разделом.

## Основные возможности

- **Авторизация:** регистрация, вход, сессия на JWT.
- **Треки:** список, прослушивание, создание с загрузкой аудио и обложки, редактирование, удаление (с учётом прав).
- **Настроения (mood):** фиксированный набор категорий (например, focus, energy, calm) для навигации по настроению.
- **Теги:** API и UI для тегов; администраторы могут управлять тегами.
- **Админ-панель:** просмотр и управление треками в объёме, отличном от обычного пользователя.
